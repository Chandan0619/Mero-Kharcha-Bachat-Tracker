📌 About Project
Mero Kharcha & Bachat Tracker is a web-based application designed to help users manage their finances efficiently and conveniently.<br>
The system is primarily focused on employees, enabling them to:<br>
   ● Track income and expenses<br>
   ● Manage budgets effectively<br>
   ● Build savings habits<br>
   ● Set reminders for future payments<br>

It simplifies personal finance management through automation and clear reporting.<br><br>
**✨ Features**<br>
💵 Income & Expense Management:<br>
   ● Add and track income<br>
   ● Record daily expenses<br>
   ● Categorize financial activities<br>
📊 Budgeting:<br>
   ● Set weekly and monthly budgets<br>
   ● Monitor spending against budget<br>
⏰ Reminders:<br>
   ● Set reminders for upcoming payments<br>
   ● Avoid missed deadlines<br>
📈 Reports:<br>
   ● Generate income and expense reports<br>
   ● Get a clear overview of financial status<br>
💰 Auto Savings:<br>
   ● Automatically saves 20% of income<br>
   ● Emergency access to saved funds<br><br>
**🛠️ Tech Stack**<br>
   ● Frontend: HTML, CSS, JS<br>
   ● Backend: Python (Django Framework)<br>
   ● Database: MySQL<br><br>
**🎯 Target Users**<br>
   ● Employees<br>
   ● Individuals managing personal finances<br><br>
