## 📌 About Project
Mero Kharcha & Bachat Tracker is a web-based application designed to help users manage their finances efficiently and conveniently.

The system is primarily focused on employees, enabling them to:
- Track income and expenses
- Manage budgets effectively
- Build savings habits
- Set reminders for future payments

It simplifies personal finance management through automation and clear reporting.

---

## ✨ Features

### 💵 Income & Expense Management
- Add and track income
- Record daily expenses
- Categorize financial activities

### 📊 Budgeting
- Set weekly and monthly budgets
- Monitor spending against budget

### ⏰ Reminders
- Set reminders for upcoming payments
- Avoid missed deadlines

### 📈 Reports
- Generate income and expense reports
- Get a clear overview of financial status

### 💰 Auto Savings
- Automatically saves **20% of income**
- Emergency access to saved funds

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JS
- **Backend:** Python (Django Framework)
- **Database:** MySQL

## 🎯 Target Users
- Employees
- Individuals managing personal finances
